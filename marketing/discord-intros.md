# Discord Intro Messages

Short, server-aware introductions for 5 MTG-adjacent Discord servers. The voice is mine (the creator). Each lands in the relevant channel — usually `#self-promo`, `#tools`, or `#community-projects`, never the general chat. Always read the rules and pinned posts first; some servers require modmail approval before posting tools.

**Posting protocol:**

- Read the server rules and check pinned messages before posting.
- If the server has a self-promo channel, use it; never post tools in general chat.
- Post once. Reply to questions for the first 48 hours.
- If a mod removes the post, DM them to ask what's allowed.
